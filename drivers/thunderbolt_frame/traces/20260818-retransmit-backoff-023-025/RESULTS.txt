== NCCL timeout math (recorded for the commit)
NCCL passes qp attr timeout=18 -> 4.096us * 2^18 = 1.07 s first retransmit (stock);

== Ring-wedge finding (operational, repeated 3x today)
Ring teardown/re-create WITHOUT a reboot (tbrxe/tbframe reload, or the peer
rebooting) wedges one side's NHI TX ring (driver_head advances, nhi_tail stays 0)
roughly every other event: 21:12 both-reload -> 025 wedged; 21:40 tbrxe-only
reloads -> BOTH wedged (023's discovered later); 22:0x 023 reboot -> 025 wedged.
This is the router-egress credit wedge class (reset-only recovery) the BYE/READY_ACK
spec work targets. Operational rule adopted for the campaign: deploys and recoveries
go via reboot (one node at a time), and every link re-establishment is verified
bidirectionally (ib_send_lat both ways or counters) before any workload.
